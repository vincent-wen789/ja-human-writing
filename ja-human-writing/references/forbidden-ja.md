# 日本語の表現チェック表

stop-ai-slop-jp、slop-nuki、natural-japanese の表現集などをもとに再構成したもの。複数の表で同じ語が挙がっていても、独立した実証とは限らない。研究の範囲は [evidence-ja.md](evidence-ja.md) を参照。

すべて確認の手掛かりであり、禁止語や自動置換の一覧ではない。書き手の声、レジスタ、具体的な読みにくさを見て判断する。回数だけで削らない。

事実、引用、否定、条件、確信の度合い、書き手の立場を保つ。行為者・因果・体験を作らない。自然な原文はそのまま残す。

## §1 定型句

次の表現は、内容のない前置きや締めになっていないかを確認する。実際の質問、誘い、案内、作者の語り口として働くなら残す。「人間はほぼ書かない」とは扱わない。

- 締め：いかがでしたか／ぜひ〜してみてください／ぜひ参考にしてください／〜に他なりません／○○の重要性を再認識しました
- 冒頭：近年〜が注目されています／現代社会において〜／今回は〜について紹介します／解説していきます
- 断言や姿勢：言うまでもなく／正面から扱う／探求する
- 自称や案内：本稿／本記事／筆者／本章では〜。文書の種類に合えば使える
- 推量の締め：〜と言えるでしょう／〜ということになるでしょう／〜のではないでしょうか。限定や問いを消さず、同じ内容の重複だけ整理する

「さて」「それでは」はスレッドの転換に使える。「最後に」「まさに」「重要なのは」「このように」「不可欠」も、語そのものを理由に削らない。

## §2 抽象語・横文字

具体的な説明の代わりに語を置いていないかを確認する。単語数で判定しない。

- 質感：泥臭い／手触り／肌感／体温・温度感／熱量／血の通った
- 認知：解像度／腹落ち／メンタルモデル／文脈／言語化する
- 評価：本質的／地に足のついた／等身大／営み／装置／思想／哲学
- 形容：核心的／鍵となる／根本的な／多角的／包括的／総合的

「思考のOSをアップデート」「人生をハック」「習慣をインストール」などが空疎なら、考え方を変える、工夫する、習慣をつける、と具体化できる。ただし、意味や作者の声を担う比喩は残す。

カタカナやビジネス用語は読者と意味で選ぶ。コンテキスト／アライメント／ナレッジ／インテグリティ／コミット／レバレッジ／ROI／ピボットには専門的な意味もある。普通の語にすると不正確になる場合は置換しない。

## §3 壮大な語彙と比喩

素材以上に大きく言っていないかを見る。文学的な文体や必要な概念は残す。

- 真理・真実／宿命・運命／境地・極致・究極／虚飾・虚像／美学・徳・品性
- 深淵／禁欲的・優美・優雅／残酷・冷徹・冷酷／凝縮・結晶・結実
- 地図・羅針盤・コンパス／仕様書・レシピ／土台・柱・骨格／エンジン・潤滑油／DNA・車の両輪／触媒

「結局HHKBのほうが好きだった」で足りる感想を大げさにしない。一方、理解や面白さを支える比喩を、テンプレ語という理由だけで削らない。人間らしさを足すために新しい比喩へ置き換える必要もない。

## §4 主体と立場

無生物主語、受動態、省略された主語は、それだけでは問題にならない。対象が分からず理解に支障がある場合だけ、原文の情報から補う。

| 表現 | 編集判断 |
|---|---|
| データが示している | データが結論を支えていれば残す |
| 文化が醸成される | 根拠なく「経営陣が文化を作った」と行為者を足さない |
| 課題が浮き彫りになる | 原文に体験がなければ「やってみて気づいた」にしない |
| 議論が深まる | 原文に具体的な争点があれば示す。なければ作らない |
| プロセスが定着する | 「みんながやるようになった」と対象を広げない |

「示唆している」「位置づける」なども、関係が明確なら残す。「多くの人」を根拠なく「自分は」「自分の会社では」に置き換えない。

比較やレビューでは判断の条件を説明する。「場合による」で終わっていて材料があるなら条件を示すが、購入・選択・断念の体験は作らない。「注意が必要」を勢いのために「やるな」へ強めない。

「可能性がある」「場合がある」「とは限らない」は別々の不確実性を伝えられる。段落内の上限は設けず、同じ限定の重複だけ整理する。免責や留保も、対象やリスクが異なるならそれぞれ残す。

## §5 構造とリズム

- **AではなくB**：架空の誤解や反転の連発を確認する。実際の訂正・比較と、Aへの否定は残す。
- **主張を含む見出し**：それ自体は問題ない。本文冒頭が同じ主張を繰り返すだけなら、その重複を整理する。明確な見出しを「○○の話」へ薄めない。
- **予告・番号・三点セット**：「順に見ていきましょう」が不要なら削れる。実際の案内、手順、独立した三つの理由は残す。
- **均一な文長・段落長**：それだけで直さない。極短文や脱線を足して散らばりを作らない。
- **同型の締めや体験→引用→教訓**：反復が内容を進めているかを見る。必要な並列や意図的な反復は残す。
- **文末**：敬体は連続して使える。「たい」「思う」「か」は人間専用の表現ではなく、多様性のために足さない。
- **感嘆や共感**：「驚くべきことに」「興味深いことに」「なんですよね」が内容から浮いていないかを読む。

## §6 敬語（ビジネス文書）

適切な挨拶、宛名、名乗り、依頼のクッション、尊敬語・謙譲語、お詫び、結びは保つ。正しい敬語を一律に削らない。

- 敬語が重なりすぎていれば整理する：お伺いさせていただきます→伺います、拝見させていただきました→拝見しました、おっしゃられていました→おっしゃっていました
- 「させていただく」は許可・恩恵と場面を確認する。自分の行為の説明なら「いたします」「します」で足りることがある
- 「恐れ入りますが」「お手数ですが」「誠に勝手ながら」が同じ依頼に重なるときは必要なものを残す
- 「何を・いつまでに」が読み取れないときは用件を明確にする
- 自分側への尊敬語や、社外に対する身内の扱いを確認する：私がお越しいたします→伺います、弊社の社長がおっしゃって→申して
- 慣用に合わない「おスケジュール」などを直す。丁重さが必要な場面を無理に短くしない

## §7 漢語のレジスタ

文脈上必要な語尾が欠けているときは補う。例えば「可用性」「所要時間」「優先度」。ただし「妥当」「透明」など単独で正しく使える語まで一律に名詞化しない。

口語では「齟齬→食い違い」「所感→感想」などが合うこともある。意味を確認して選び、社外の正式文書や専門文書の定着語を無理に和語へ直さない。

## §8 記号

- 対応の取れない Markdown や意図しない空白は直す。コード、リンク、引用、指定された形式は保つ。
- ダッシュ、コロン、「」、絵文字は間・説明・引用・語気を担える。文字単位の一括置換をしない。
- 中黒の並列、番号、比較表も正当な情報整理。構造を壊したり項目を落としたりしない。
