# 日本語 禁止パターン集(統合版)

stop-ai-slop-jp(phrases/structures)、slop-nuki(keigo/kango)、natural-japanese(forbidden-patterns、コーパス校正済み)、および 2026-08 の日本語圏調査を統合した。信頼度の表記:**[実測]** = コーパスか研究で数値化済み/**[多源]** = 独立した3つ以上の情報源/**[単源]** = 迷ったら緩めに。

> 鉄則:命中 ≠ 違反。「ゼロ容認」2類を除き、すべて SKILL.md の gut-check(書き手の声か・レジスタ由来か)を通してから判定する。1〜2回は自然な日本語で、**撒く(頻出)から slop になる。**
> **数値の閾値は SKILL.md §4 の表が唯一の典拠**——本ファイルは語彙の中身だけを管理し、矛盾したら表に従う。

## §1 定型句(2段構え:強表はゼロ容認/密度判定は gut-check)

**[実測]** natural-japanese コーパス校正(人間 103 篇 vs AI 81 篇)+ 多源。

**強表(ゼロ容認。人間がほぼ書かない)**:

- 締め:いかがでしたか/いかがでしたでしょうか/ぜひ〜してみてください/ぜひ参考にしてください/〜に他なりません/○○の重要性を再認識しました
- 冒頭:近年〜が注目されています/現代社会において〜は重要なテーマです/今回は〜について紹介します・解説していきます・深掘りしていきます
- 空の断言:言うまでもなく/言うまでもありません
- 姿勢の宣言:正面から扱う/正面から見る/〜を探求する/本章では〜(姿勢は内容を生まない。内容を直接書く)
- ブログ本文への学術自称:本稿/本記事/本論考/筆者

**密度判定(命中≠違反。連発したら削る)**:

- 推量の締め:〜と言えるでしょう/〜と言えるだろう/〜ということになるでしょう/〜のではないでしょうか/結論から言うと(で結論が薄い)——単発は gut-check、連発は slop
- 転換句:さて、/それでは、——lint は info 扱い。SNS スレッドの転換は免除(SKILL.md 短文プロファイル)

**[実測・免除]**「最後に」「まさに」は AI 語ではない——コーパス実測で人間の方が圧倒的に多い(48:2/24:0)。消さない。「重要なのは」「このように」「不可欠」も人間が普通に書く弱シグナルで、既定は残す。

## §2 偏愛語・横文字(撒布密度で判定)

**[多源]** 質感・認知・評価を「装う」語(単発は正当。一記事3個以上で slop):

- 質感系:泥臭い/手触り/肌感/体温・温度感/熱量/血の通った
- 認知系:解像度(が上がる)/腹落ち/メンタルモデル/文脈(やたら言いたがる)/言語化する
- 評価系:本質・本質的/地に足のついた/等身大/営み/装置/思想/哲学
- 空の形容:核心的/鍵となる/根本的な/多角的/包括的/総合的(実際の角度を書いて初めて意味を持つ)

**[多源]** 横文字メタファー(IT 用語の比喩転用。全部普通の日本語に戻す):

思考のOSをアップデート→考え方を変える/人生をハック→工夫する/習慣をインストール→習慣をつける/マインドをリファクタリング→考え方を整理する/学びをアセットにする→学びを積み上げる

**[多源]** カタカナ過剰(戻せるものは戻す。本物の技術用語は免除):

コンテキスト→文脈/アライメント→揃える/ナレッジ→知識/プライオリティ→優先/インテグリティ→誠実さ/コラボレーション→連携

**[多源]** ビジネスジャーゴン:〜にコミットする/レバレッジを効かせる/ディープダイブ/ROIを最大化/ピボットする→どれも普通の日本語で言える

## §3 壮大化語彙(一記事2個以上で slop)

**[多源]** 普通の感想を人類の命題に仕立てる漢字熟語:

真理・真実/結末・宿命・運命/境地・極致・究極/虚飾・虚像/美学・徳・品性/重厚感・深淵/禁欲的・優美・優雅/残酷・冷徹・冷酷/凝縮・結晶・結実

複合使用(「枯淡の境地」「残酷な真理」「虚飾を剥ぎ取る」)は一発アウト。AI は文芸評論の文体を大量に学習していて、放っておくと中二病方向に寄る。**直し方:普通の感想は普通の語彙で**——「結局HHKBのほうが好きだった」に「僕の指先が感知した違和感の正体とは」は要らない。

**[多源]** 比喩のテンプレ語(同一記事3回以上で slop。§5 実証のとおり、直すときは削る方向。新しい比喩は足さない):

地図・羅針盤・コンパス/仕様書・設計書・レシピ/土台・柱・骨格/栄養・エンジン・潤滑油・スパイス/DNA・車の両輪/触媒・起爆剤

## §4 主体と立場(構造層。語彙は症状にすぎない)

**[多源]** False agency——無生物が人間の動詞を取る。誰が何をしたかに書き換える:

| AI 版 | 人間版 |
|---|---|
| データが示している | データを見るとこうなってる |
| 文化が醸成される | 経営陣が文化を作った |
| 課題が浮き彫りになる | やってみて課題に気づいた |
| 議論が深まる | 話してたら細かい話まで出てきた |
| プロセスが定着する | みんながやるようになった |

翻訳調動詞は同じ症状の語彙面:指している/示唆している/物語っている/浮かび上がる/収斂する/位置づける——見たら「誰が」を立て直す。

**[多源]** 遠くから語る:人々は/多くのエンジニアが/誰もが〜はずだ/現代社会において→「自分は」「自分の会社では」。

**[多源]** 立場の回避:ケースバイケース/場合によります/一概には言えませんが/メリットもあればデメリットもあります/賛否が分かれるテーマです——全方位肯定は判断の放棄。比較・レビューでは「自分はこれを選んだ、あれはやめた」を引き受ける。

**[多源]** 弱い否定:あまり推奨されません/注意が必要です/避けたほうが良いでしょう→「やるな」と言うべき場面では言い切る。

**[多源]** 三段ヘッジ(一段落2個以上で slop):〜ことがある/〜場合がある/〜可能性がある/〜なりうる/〜とは限らない/〜と言えなくもない。

**[多源]** 儀式化した免責:あくまで個人の見解であり〜/環境によって結果は異なる可能性が〜——節ごとに保険を掛けると立場が消える。**一記事1箇所まで**(SKILL.md の表と同じ)。

## §5 構造とリズム

**[多源]** 反転構文(telegraphed reversal の直輸入):Aではなく、Bだ/単なるAではなくB/実はAではなくBだった/Aでもない、Bでもない、Cだ/劇的な断片化(シンプル。それだけ。それが本質。)——**長文3回以上で構造的 slop。** 実在する誤解の訂正は単発なら正当。

**[多源]** 命題型H2:見出しに主張を置く(「○○もまた同じ方向を指している」)→名詞句に(「○○の話」)。H2 の主張を本文冒頭で言い換えて繰り返すのは悪化版。

**[多源]** メタ構造宣言:以下の3つの観点から/それぞれ順に見ていきましょう/ここからが本題です/STEP1→全部消して、1つ目を直接書く。

**[多源]** 三点セットの強制:大きく分けて3つの理由が〜——数は先に決めない。論点の数だけ書く。

**[実測+多源]** ムラの欠如(リズムの均一化。統計層の主指標で、lint が大半を測る):

- 段落の長さ・文数が全篇で揃う(AI の段落は 90〜160 字に集中。人間は 200 字超も1行も混ざる)
- 全段落が同型で着地(〜なんだなと感じました/〜が分かりました)
- 体験→「」引用→抽象化のテンプレを3節以上連発
- 文末が一本調子(実測:AI は である/だ/ている が 75% 超、「たい」「思う」「か」はゼロ——人間専用の文末は使ってよい)
- 着地が全部きれい:結論を保留する段落、脱線して終わる段落があってよい

**[多源]** 感嘆と共感の演出:驚くべきことに/興味深いことに/実は(乱用)/〜なんですよね(密集)——演出だけ浮いて中身が伴わないと空々しい。

## §6 敬語の slop(ビジネスレジスタ専用。slop-nuki の独自観点)

> **先に「残すもの」**:社外メール冒頭の定型挨拶(1回)/宛名と名乗り/依頼前のクッション(1つ)/一段の正しい尊敬語・謙譲語/恩恵が実在する「させていただく」/お詫びの丁重さ/結びの定型(1回)。**ビジネスレジスタで正しい敬語は slop ではない。一律に削るのは別種の slop。**

- **二重敬語**:お伺いさせていただきます→伺います/拝見させていただきました→拝見しました/おっしゃられていました→おっしゃっていました
- **させていただく の濫用**:許可・恩恵が実在しない自分の行為→いたします・します(開始させていただきます→開始いたします)
- **クッションの連打**:恐れ入りますが+お手数ですが+誠に勝手ながら の重ね→1つ残す
- **慇懃無礼**:敬語を積みすぎて「何を・いつまでに」が読めない→用件を一文で
- **方向の取り違え**:自分側に尊敬語(私がお越しいたします→伺います)/社外向けに身内へ尊敬語(弊社の社長がおっしゃって→申して)
- **美化語の付けすぎ**:おスケジュール/おメールアドレス→慣用外の「お/ご」は削る
- **冗長な語尾**:お願い申し上げる次第でございます→お願いいたします

## §7 漢語のレジスタ(slop-nuki の独自観点)

**削られた裸のコア**(完全形に戻せば直る):妥当(→妥当性)/一貫(→一貫性)/実効(→実効性)/網羅(→網羅性)/可用(→可用性)/優先(→優先度)/透明(→透明性)/所要(→所要時間)

**抽象漢語への持ち上げ**(口語の場では和語に戻す):認識です→そう思っています/齟齬→食い違い/乖離→差/展開します→共有します/所感→感想/醸成→育てたい/懸念事項→気になっている点

**免除**:社外の正式文書・専門文書の定着語(実施/精査/訴求/競争優位/顕在化…)は正用。過剰に和語化するのはレジスタ錯誤で、これも slop。

## §8 記号(ゼロ容認。検索して置換)

- **全角ダッシュ ──**(em-dash の直輸入):読点・改行・コロンに置換 **[多源]**
- **対応の取れない `**`**・コロン後の半角スペース・全角文中の半角スペース(コード・リンク・正当な Markdown 強調は免除)**[多源]**
- 装飾絵文字の均等撒布(🚀🎯✨💡 が段落末に等間隔)**[多源]**
- 形容詞・心情への「」(「軽い」「動けばヨシ」):固有名詞と直接引用以外に使わない。「」内の造語が一記事3箇所以上は金句の量産 **[多源]**
- 中黒並列 A・B・C の三連:「と」「や」でつなぐ **[多源]**
- ❌/✅ の bad-then-good 対比:地の文に展開する **[単源]**
